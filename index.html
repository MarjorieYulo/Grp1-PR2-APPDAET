The problem

Get the Mouse to the Cheese

  • 16 x 16 maze
  • Squares are (row, column). (0,0) is the top left.
  • The mouse moves up, down, left, right.
  • It can't walk through walls.
mousecheesewall
Algorithm 1 • finds the shortest path

BFS (Breadth-First Search)

Like a ripple in water: it checks the closest squares first, then moves outward.

  1. Start at the mouse.
  2. Check the squares next to it.
  3. Put new squares in a waiting line (the queue).
  4. Repeat until it reaches the cheese, then trace the path back.
waiting in linecheckedshortest path
Algorithm 2 • from PR1 feedback

Wall Crawl

The mouse keeps its right hand on the wall and follows it.

  1. Start facing right.
  2. Try: right → straight → left → turn back.
  3. Move to the first open one.
  4. Stop if it finds the cheese, or if it's back on the same square facing the same way (a loop).
